## 基本資訊

- 日期：2026-09-21
- 測試人員：（開發者本人）
- 版本：alpha-1.0.0（未升版；本批是修正與版面）
- 變更／功能範圍：
  1. **修 bug**：完成度長條圖的日期被折成兩行、第二行被裁掉 → 以長條為中心、不限寬
  2. **修 bug**：完成度頁最後一張卡片被 Android 導覽列蓋住 → 下內距加上 `viewPadding.bottom`
     （關聯圖的摘要卡同步處理）
  3. 目標頁／願景頁套用 2026-09-16 畫布的 **A 卡片稿**：38px 圖示方塊、標題 700、
     子項改成卡片內的輕量勾選列、頁首副標帶總量
  4. **回退**：四張 sheet 的輸入框改回 Material 浮動標籤（`SheetTextField` 保留，只換內部實作）
  5. **沒有分類就什麼都不畫**：色條無色、圖示方塊空著；沒有分類但連了願景時，
     整張卡片與底下的任務都改用**那個願景的顏色**（小工具同步）
  6. sheet 下拉關閉門檻 90px → **40px**
