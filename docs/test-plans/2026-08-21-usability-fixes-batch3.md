## 前置條件

⚠️ **必須先在 Supabase SQL Editor 執行**，否則第 11 項的每月日期無法持久化：

```sql
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS recurrence_month_days int[];
```

（未執行前其他功能不受影響——`toJson()` 只在該欄位有值時才輸出它。）

## 備註：已知但**不在**本批範圍

1. **「清空回收桶」只清記憶體不刪雲端**：`trash_screen.dart` 呼叫 `TrashNotifier.clear()`，
   但該方法只重設狀態並把 `_userId` 設為 null，導致該 session 後續所有刪除都靜默失敗，
   且重新載入後資料會回來。需要獨立的 `emptyAll()`。
2. **目標／願景刪除只快照根節點**：`remove()` 會遞迴刪除整棵子樹，但只有根節點寫入回收桶，
   子孫永久遺失。本批只修好了**任務**這一側。
3. `trash_screen.dart` 有三處硬編中文字串未走 l10n。
4. ⚠️ 本批曾對三個畫面檔誤跑 `dart format`，造成大量非必要的排版變動（詳見交付說明）。
