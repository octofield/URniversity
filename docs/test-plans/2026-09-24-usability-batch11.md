# 測試計畫：使用回饋第十一批（重複任務通知、排序模式、全文顯示與字數上限、widget 尺寸、分類帶入、同步失敗）

> [../system_design.md](../system_design.md)（§2-B、§2-C、§2-K、§3-C、§3-I、§3-K、UC3-B、UC4、UC5-B、UC13、UC14）。

## 基本資訊

- 日期：2026-09-24
- 測試人員：（開發者本人）
- 版本：alpha-1.0.0
- 變更／功能範圍：
  1. **沒設時間的重複任務**在它落到的每一天、於設定的時刻通知（預設 08:00，設定 → 通知 → 任務到期可調）；
     有時間的重複任務維持原樣
  2. 排序 sheet 最下面多一列「**調整順序**」：切回手動並在每列顯示把手，**按住把手直接拖**，不用長按；
     頁首排序鈕變成「完成」
  3. 任務／目標／願景標題**全文顯示**不再兩行截斷；**所有使用者輸入都有字數上限**，
     會存進資料庫的欄位在資料庫也加了 CHECK（`supabase/input_length_limits.sql`）
  4. 小工具可以**縮到 3 欄**，窄於 250dp 時換成精簡版面
  5. 目標頁與願景頁加上**與任務頁相同的排序鈕與排序方式**
  6. 目標連結願景時、目標沒有分類就**帶入願景的分類**；新增子目標時**預先帶入父目標的分類**
  7. 「開著 App 一段時間後再點開偶爾同步失敗」：token 更新失敗（`AuthRetryableFetchException`）納入重試、
     重試拉長到 5 次約 6 秒、`reload()` 失敗不再讓之後的寫入全部靜默失效
