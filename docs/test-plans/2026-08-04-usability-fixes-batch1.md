1. `everyNDays` 間隔填 0 會讓 App 崩潰（`% 0` 拋 `IntegerDivisionByZeroException`）。
2. `data_structure.dbml:55-56` 已與程式碼脫節（仍寫 `is_recurring` / `recurrence_rule`）。
3. `Task.copyWith` 無法把 `content` 清成 null。
4. 父節點自身 `isDone` 不影響其子節點進度條（§2-C 已記錄為刻意語意）。
5. 第二批（第 6、7、9 項）需要先手動執行 `ALTER TABLE`，見計畫檔。
