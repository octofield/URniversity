## 發現的問題

1. **（已修）左欄時間標籤消失**：`if … for … if … else for …` 的 else 接到內層的 if，沒有節次表的學校完全沒有標籤，台大則每個範圍外的節次都多疊一整組整點標籤。
2. **（已修）清大系名去不掉兩個字母的班別**（「數學系115BA」）：正規式只去一個字母。
3. **（已修）刪除帳號沒有刪 `courses`、`reviews`。**
4. **（設計調整）移除後的「復原」提示**：snack bar 在 sheet 後面的頁面上，被遮罩擋住按不到；改成結果列直接變回可加入。
5. **（設計調整）多一個「不計」類別**：體育在清大開放資料裡對很多系是必修，但兩校都不計畢業學分。
6. **（限制）清大畢業學分只有 PDF**：暫時自填；台大學士後護理學系的頁面格式不同，也要自填。
8. **（已修）醫學系等有組別的系讀不到**：系所清單的 `data` 代碼少了組別，改用表單實際送出的 `value`（例如醫學系 40100）。
7. **（未確認）同步失敗的真正原因**：修了已知的上下限不一致並加上重試與紀錄；下一次失敗時請看同步紀錄。
