## 基本資訊

- 測試人員：（開發者本人）
- 變更範圍：`newRowId()`（`src/lib/providers/synced_list_notifier.dart`）
- 回報的錯誤：網頁版按「新增」任務時

  ```
  RangeError: max must be in range 0 < max ≤ 2^32, was 0
  math_patch.dart nextInt ← synced_list_notifier.dart newRowId ← tasks_provider.dart add
  ```

## 原因

`newRowId()` 用 `Random().nextInt(1 << 32)` 做亂數後綴。在 VM（Android、桌面、`flutter test`）
上 `1 << 32` 是 4294967296；但**網頁上所有 int 都是 JavaScript number，`<<` 只算 32 位元**，
`1 << 32` 會變成 **0**，`nextInt(0)` 直接拋例外。

影響範圍：**網頁版所有新增都會失敗**——任務、學期目標、願景、靈感、日記，全部走 `newRowId()`。
由 2026-08 的 `2414161`（修 id 碰撞）引入；VM 上的自動測試全綠，所以沒被抓到。
