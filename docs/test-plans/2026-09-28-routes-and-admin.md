## 發現的問題

1. **（已修）`context.go` 會關掉開在分頁上面的頁面**：分頁上面有頁面時只換索引，頁面關掉後才更新網址。
2. **（測試注意）`tester.pageBack()` 找英文的「Back」提示**：中文介面要改點 `BackButton`。
3. **（限制）訪客不在統計內**：訪客資料只在裝置上。
4. **（限制）停用帳號**：已登入的工作階段最多一小時後才失效（access token 到期）。
5. **（新的資料蒐集）** 每日活躍紀錄與錯誤回報，若有隱私權說明需一併更新。
