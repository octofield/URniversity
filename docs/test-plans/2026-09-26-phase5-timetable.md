## 發現的問題

1. **（設計調整）課程網封鎖程式化存取**：改用 NOL，並記錄在腳本與 README 中不要碰 `course.ntu.edu.tw`。
2. **（設計調整）時段改存同一列 jsonb**：避免背景寫入順序造成外鍵拒絕。
3. **（已修）Python 3.13 拒絕 NOL 的憑證**（缺 Subject Key Identifier）：只關掉嚴格模式那一個旗標，仍驗證憑證鏈與主機名稱。
4. **（已修）sheet 裡的 ListTile 需要 Material**：以透明 Material 包住，否則觸發框架斷言。
5. **（限制）課程目錄只有台大**；其他學校用手動新增與時鐘時間。
